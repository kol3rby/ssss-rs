## [0.5.8] - 2026-07-24

Idiomatic-Rust release. Internally this refactors the faithful 0.5.7 port into
more conventional Rust; the share wire format and combine behavior are unchanged.
Shares stay mutually interchangeable with the C build, and the full test suite
(field, diffusion, golden-file interop, and cross-combine) remains green
byte-for-byte.

### Changed

- Collapsed `enum ssss_errcode` and its parallel `ssss_errmsg[]` table into a
  single `Error` type whose messages live in a `Display` impl (implementing
  `std::error::Error`); `fatal_errcode` dissolves into that `Display` plus the
  one `fatal()` print site.
- Expressed field arithmetic through operator traits: `impl Add`/`Shl` for
  `&Fe` (with `Sub` deliberately unimplemented, since subtraction is addition in
  GF(2)), and `field_mult`/`field_invert` as `Field::mul`/`Field::invert`.
- Replaced the `_init`/`_deinit` pairs with constructors and `Drop`: `Cprng::open`
  (fd closed on drop) and `Field::new` (reset via ownership); `cprng_deinit` and
  `field_deinit` are gone.
- Split the mutable `Ctx` god-struct into an immutable `Opts` (parsed once, with
  `opt_` prefixes dropped and `-1`/`0` sentinels replaced by `Option`) plus the
  transient run state.
- Narrowed the diffusion layer's public surface to `encode`/`decode`, dropping
  the `encdec` enum from the API and taking the block cipher as an `impl Fn`
  closure instead of a raw function pointer.

## [0.5.7] - 2026-07-24

Initial release: a faithful, byte-for-byte compatible Rust port of
B. Poettering / J. Frisby's `ssss` v0.5.7
([ssss.c](https://github.com/MrJoy/ssss)). Shares generated by the C build and
this port are mutually interchangeable, and given the same secret and random
stream the two emit identical shares.

### Added

- `ssss-split` and `ssss-combine` binaries, built from one entry point with
  dispatch on the invoked program name (mirroring the original hard-link trick).
- Pure-Rust GF(2^deg) field arithmetic: arbitrary-precision field elements over
  little-endian bytes with carry-less multiply/invert; no GMP dependency.
  `Fe::export`/`Fe::import` reproduce every `mpz_export`/`mpz_import` layout the
  C relies on, including `encode_mpz`'s `order=-1, size=2, endian=1`.
- XTEA-based diffusion layer, Shamir polynomial evaluation (`horner`/`horner_r`)
  and Gaussian-elimination reconstruction (`restore_secret`).
- Full CLI surface, byte-compatible with the C tool: threshold/number
  (`-t`/`-n`), security level (`-s`), token prefixes (`-w`), hex mode (`-x`),
  recovery mode (`-r`), quiet/extra-quiet (`-q`/`-Q`), diffusion disable (`-D`),
  version (`-v`), help (`-h`), and memory-lock enforcement (`-M`). Prompt
  strings, error messages, exit codes, and share wire format all match.
- Security posture ported from the original: `mlockall`, privilege drop, echo
  suppression during secret entry, `/dev/urandom` as the only entropy source,
  and volatile zero-on-drop of secret-bearing buffers (`secure_zero`, the RAII
  replacement for GMP's zeroing allocator hooks).
- `mlock` Cargo feature (default on); `--no-default-features` builds the
  `NOMLOCK` equivalent (drops memory locking and the `-M` flag).
- Test suite: field-arithmetic unit tests (inverse round-trips at
  degrees 8/64/128/256/1024), diffusion encode/decode identity tests (including
  the `degree % 16 == 8` byte-fixup degrees), and integration tests with
  golden share vectors captured from the reference C build asserting
  byte-for-byte identical generation, plus self round-trips.
- `SSSS_RANDOM_SOURCE` environment override for deterministic randomness in
  tests (defaults to `/dev/urandom`, so production behavior is unchanged).
- Packaging and docs: the upstream man page source (`ssss.manpage.xml`) with a
  thin `Makefile` (`make doc`) that generates `ssss.1` via `xmltoman`; `README`;
  GPLv2 `LICENSE`; `.gitignore`; and a Dependabot config for the crate.
